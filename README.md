# Omnidot

Marketing website for [Omnidot](https://omnidot.gr) — a Athens-based agency for websites, social media, SEO & AEO, and performance ads.

Built with Vite, React, and TypeScript; deployed on Cloudflare Pages.

## Tech stack

- Vite · React · TypeScript
- React Router

## Run locally

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## Deploy notes

Cloudflare Pages (typical settings): framework Vite, build `npm run build`, output `dist`, Node 20+.
