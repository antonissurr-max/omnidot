# πυργιώτης — brand system

Geometric identity for **Πυργιώτης ΟΕ** (structural engineering), inspired by the Pathway lockup language: two overlapping solids, black + warm stone, lowercase wordmark.

## Palette

| Token | Hex | Note |
| --- | --- | --- |
| Black | `#0D0D0D` | Primary mark stroke |
| Warm stone | `#C9B196` | Pantone 480–adjacent; column + wordmark |

## Files

| File | Use |
| --- | --- |
| `mark.svg` | Icon only |
| `logo.svg` / `logo-stacked.svg` | Primary stacked lockup (EL) |
| `logo-stacked-en.svg` | Stacked lockup (EN) |
| `logo-horizontal.svg` | Horizontal lockup |
| `logo-integrated.svg` | Mark as π + rest of name |
| `logo-inline.svg` | Wordmark inside the portal |
| `logo-dark.svg` | On black |
| `logo-mono.svg` | Greyscale |
| `logo-partner.svg` | Light lockup for dark UI |
| `brand-board.svg` | Full identity sheet |

Regenerate from repo root:

```bash
python3 scripts/build-pyrgiotis-brand.py
```
